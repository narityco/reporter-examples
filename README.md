# Render a report to PDF with Narity Reporter

Run this .NET 10 example on Windows, Linux, or macOS.
It uses three fictional orders in an open JSON report definition.
No database or SAP runtime is required for the sample.

## Get the SDK

1. [Create a Reporter account](https://reporter.narity.com/register.html?utm_source=example&utm_medium=repository&utm_campaign=discoverability).
2. Verify your email.
3. Start the 30-day evaluation from your account.
4. Download your `Narity.Reporter` NuGet package.

Install the .NET 10 SDK. Put your downloaded package in a new `packages` folder beside `FirstPdf.csproj`.
The project selects the latest version in that folder, including preview versions.
The source mapping restores `Narity.Reporter` only from that folder.
Other dependencies come from nuget.org.

The account package contains your licence. Keep the package and any image containing it private.
The example's MIT licence covers its code and fictional sample. The Reporter SDK has separate commercial terms.

## Render the sample

Run these commands from the example folder:

```sh
dotnet restore --packages ./packages-cache
dotnet run --no-restore
```

Open `out.pdf`. Expect one page titled **Order summary**, containing ORD-1001, ORD-1002, and ORD-1003.
Compare it with `expected.pdf`.
The expected PDF was generated by Reporter and carries its unlicensed watermark.
A valid evaluation package produces clean output.
This JSON sample demonstrates the rendering pipeline. It does not measure Crystal Reports compatibility.

## Try a saved Crystal report

Keep your report on your machine. Pass the path to an `.rpt` file saved with data:

```sh
dotnet run --no-restore -- /path/to/report.rpt
```

On Windows, pass a Windows path instead. The command writes `out.pdf` in the current directory.
It uses the report's saved rows and saved parameter values.
Compare the result with the PDF from Crystal using the same data and parameters.

Reports without saved data need a database provider or rows supplied by your application.
SQL Command reports need supplied rows.
The SDK targets .NET 10. It cannot be referenced directly from earlier .NET applications.
Reporter is in preview. Check fonts, pagination, formulas, subreports, and totals before replacing a reporting workload.

## Run on Linux with Docker

Use a Linux container engine. Keep the SDK package in `packages`, then run:

```sh
docker build -t reporter-first-pdf .
docker run --rm -v "$PWD:/work" reporter-first-pdf
```

Run the Docker commands from a POSIX shell, such as Bash or zsh.
The mounted folder receives `out.pdf`.
To render your saved report, put it in that folder and append its filename:

```sh
docker run --rm -v "$PWD:/work" reporter-first-pdf report.rpt
```

The image contains your licensed SDK. Keep it in a private registry.
The default image includes ICU and Reporter includes fallback fonts.
Supply the report's original fonts when their licences allow it, then repeat your output comparison on Linux.
